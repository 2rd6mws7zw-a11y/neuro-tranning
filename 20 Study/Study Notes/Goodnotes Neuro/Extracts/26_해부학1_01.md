<트레이닝 성공 공식>
TR(s) = Para : Kn, Ty, Exp, Sol, Env
1. Para : Paradigm 어떤 패러다임(무기)을 장착하고 있는가?
2. Kn : Knowing 어디까지, 얼마나 알고 있는가?
3. Ty : Type 어떤 운동을 시키는가?
4. Exp : Experience 얼마나 경험이 많은가?
5. Sol : Solution 문제 해결력이 있는가?
6. Env : Environment 연습, 적용할 환경에 노출되어 있는가?
-> 이 6가지 변수에 의해 트레이닝의 성공이 결정된다.
<Knowing part : 당신이 알아야 할 지식>
우리가 하는 트레이닝은 해부학을 기반으로 한다.
해부학을 단순히 근육과 뼈, 관절로만 바라보지 마라.
전체 시스템을 알고, 시각화 할 수 있어야 한다.
1) 인체의 단계적인 접근법 필요
① 세포(출발점) -> 조직 -> 기관 -> 기관계통 -> 사람
* 세포 cell : 중요한 의미가 있음, 세포는 살아가기 위해 연료(에너지 : 산소(호흡), 당) 필요
* 연료 흡수 및 섭취 안좋을 경우 -> 조직, 기관, 기관계통에 영향을 미쳐 사람에게 문제 발생
ex) 소화기계, 비뇨기계, 심혈관계 등등 사람마다 다르게 문제 발생
* 분류 : 보이지 않는 세계 (세포 -> 조직 -> 기관)
* 시각화 주요 focus 알아야 할 부분 : 기관계통 (우리의 신체를 이루는 전체 시스템이기 때문)

-> 이 시스템이 안정적이고 건강한 상태 : 항상성(homeostasis)
* 항상성이란? 문제가 생길경우 신체의 시스템이 원래대로 돌아가려고 하는 것으로 건강한 상태에서는 잘되나 불
건강한 상태에서는 무너진 시스템으로 매몰되므로 트레이닝시 초기에 통증을 빨리 잡는 것이 급선무
* 근육계 650개, 골격계 206개

구성품 기능
1. 외피계: 피부, 땀샘 보호, 온도조절

3. 골격계: 뼈, 인대 지지
