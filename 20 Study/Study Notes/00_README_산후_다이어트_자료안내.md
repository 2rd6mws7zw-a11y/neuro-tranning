- `04_뉴로다이어트_빈칸_및_필기정리.md`: 뉴로다이어트 빈칸과 필기 정리

## 사용 원칙

1. 질문에 답할 때는 먼저 요약·빈칸 정리 문서를 확인한다.
2. 세부 맥락이나 강사의 표현이 필요하면 통합 녹취와 OCR 문서를 검색한다.
3. OCR과 자동 녹취에는 오인식이 있을 수 있으므로, 애매한 내용은 원본 PDF 및 전후 문맥과 대조한다.
4. 건강·산후 관련 내용은 교육 자료로 다루며 개인의 진단이나 치료를 단정하지 않는다.
