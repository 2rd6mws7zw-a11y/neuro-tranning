# GitHub 플러그인 연결 확인

## 사용자 목표
GPT에서 전환한 플러그인에서 기존 GitHub Vault의 검색·읽기·저장 기능을 계속 사용한다.

## 확인 내용
연결된 GitHub 앱으로 main 브랜치의 99 System/Knowledge Index.md를 읽었다. 이 문서는 사용자 요청에 따른 저장 경로 확인을 위해 생성했다.

## 변경 사항
플러그인 패키지에 GitHub 앱 연결을 선언하고 기존 searchVault/readVaultFile/writeVaultFile 지침을 현재 GitHub 도구에 대응하도록 보완했다. 기존 폴더별 쓰기 제한을 유지한다.

## 검증 범위
이 파일의 생성과 재조회는 GitHub 연결의 쓰기·읽기 확인이다. 새 대화에서의 플러그인 전체 동작 검증과는 별개다.
