# GitHub 플러그인 연결 확인

## 사용자 목표
GPT에서 전환한 플러그인에서 기존 GitHub Vault의 검색·읽기·저장 기능을 계속 사용한다.

## 확인 내용
연결된 GitHub 앱으로 main 브랜치의 99 System/Knowledge Index.md를 읽었다. 이 문서는 사용자 요청에 따른 저장 경로 확인을 위해 생성했다.

## 변경 사항
플러그인 패키지에 GitHub 앱 연결을 선언하고 기존 searchVault/readVaultFile/writeVaultFile 지침을 현재 GitHub 도구에 대응하도록 보완했다. 기존 폴더별 쓰기 제한을 유지한다.

## 검증 범위
이 파일의 생성과 재조회는 GitHub 연결의 쓰기·읽기 확인이다. 새 대화에서의 플러그인 전체 동작 검증과는 별개다.

## 자동 저장 설정 — 사용자 요청 2026-09-23

사용자가 작업 내용의 자동 저장과 변경된 기존 문서의 자동 업데이트를 요청했다. 플러그인이 응답을 마치기 전에 새 작업 내용을 세션 요약에 저장하고, 명확한 변경 사항은 기존 허용 폴더의 문서에 병합하도록 지침을 보완했다. 변화가 없으면 쓰지 않으며 저장 후 재조회한다. 기존 폴더 제한을 유지하고, 저장 중지 요청을 우선한다. 대화 실행 중의 지침이며 백그라운드 상시 동기화는 아니다.

이 기록의 기존 내용은 보존하고 최신 SHA를 사용해 설정 변경 내역을 추가했다. 새 대화에서의 자동 실행 여부는 별도 확인 대상이다.
