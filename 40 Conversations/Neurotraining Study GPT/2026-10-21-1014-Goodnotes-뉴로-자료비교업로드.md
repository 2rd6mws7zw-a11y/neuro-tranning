# Goodnotes 뉴로 자료 비교·업로드 최종 기록

## 사용자 목표
Goodnotes 뉴로 폴더를 기존 GitHub 뉴로트레이닝 자료와 비교하고 없는 내용을 정리·저장한다. 오류가 난 자료를 재확인하고, 사용자가 retry 폴더에 제공한 개별 PDF까지 확인한다. 마지막 요청은 “저장해놔”다.

## 핵심 질문
기존 저장 자료와의 중복, 누락된 강의·필기, 동기화 오류 대상, retry 파일의 정상 여부와 추가 내용.

## 핵심 답변
- Goodnotes 상위·하위 뉴로 폴더에서 PDF 41개, 중복 포함 1,890쪽을 확보하고 28개 자료군으로 분류했다.
- 별도 강의·필기 22개 자료군(대표본 합계 1,188쪽)의 안내·쪽별 검색용 추출·대조 보고를 GitHub에 추가했다. 최초 저장은 정리·검색용 파일 103개와 도식·사진 13개였고, 이후 고유수용감각 손필기 보완 노트 1개 및 관련 문서 업데이트를 추가했다.
- 레벨1~4, NMT, 해부학, 산전, 고유수용감각, 혈류압박, CN12, 스트레칭·현장·줌·안전·양육 관련 자료를 구분했다.
- 기존 다이어트 2쪽/산후 5쪽 필기 PDF는 직접 읽어 추출 텍스트가 같은 것을 확인해 중복 저장하지 않았다.
- 기존 다이어트 29쪽에서 미확인이던 첫 두 수치를 원본 이미지에서 판독해 0.25~0.5%/주, 1~2%/한달로 보완했다. 강의 기록이며 개인 감량 권고가 아니다.
- 사용자가 retry 폴더에 제공한 오류 대상 6개 개별 PDF는 총 195쪽이며 모두 정상적으로 열렸다. 기존 보관본과 같은 렌더러·긴 변 1,000픽셀로 전 페이지를 비교했으며 화면 변경은 0쪽이었다.
- 마지막 고유수용감각 35쪽은 텍스트 레이어의 16쪽에서 손필기 인식 범위 차이가 있었다. 8·14·22·26·30쪽을 이미지로 확인해 기존 검색용 정리에서 빠진 필기 일부를 보완했다. 새로 쓰인 필기나 강의 개정판으로 판단한 것은 아니다.

## 결정 사항
- 저장소: 2rd6mws7zw-a11y/neuro-tranning, main.
- 강의 자료 저장 위치: 20 Study/Study Notes/Goodnotes Neuro/.
- 사용자 승인에 따라 해당 비공개 강의·필기 자료를 지정 저장소에 업로드했다.
- 기존 검토 지식과 원문은 보존하고, 검증 전 강의 주장·필기는 hypothesis 학습 초안으로 유지한다.
- 655MB 원본 ZIP 전체를 GitHub에 복제하지 않고 정리·검색용 텍스트 및 필요한 도식·사진을 저장했다.
- 중복 전체 파일을 추가하지 않고 필요한 필기 보완과 확인 기록만 반영한다.
- 이번 저장 요청에 따라 이 대화 요약을 대화 기록 폴더에 저장한다.

## 새 지식
오류는 Goodnotes 하위 뉴로 폴더의 동일 이름 복사본 6개에서 발생했다. 상위 폴더의 대응 자료는 정상적으로 내보내졌다. 사용자 제공 PDF를 통해 6개 자료 모두 읽기·비교를 마쳤다.

## 미해결 질문
Goodnotes 앱의 동기화 오류 자체는 해결됐다고 판단하지 않는다. “지금 동기화” 실행 후 동기화 완료 표시가 나와도 하위 복사본 6개의 내보내기 오류가 재현됐다. 사용자 제공 PDF의 화면은 확인했지만 PDF 전체 바이트·숨은 레이어의 동등성, 모든 손글씨의 완전 교정, 강의 효과 주장의 과학적 타당성을 검증한 것은 아니다.

## 다음 작업
후속 질문은 지식 인덱스에서 강의별 안내와 관련 쪽의 추출문을 찾아 답한다. 손글씨는 원문 이미지와 대조한다. 실제 처방·효과 주장은 별도 연구 검토를 거친다. 새 자료나 필기가 추가되면 기존 내용을 보존하면서 차이만 반영한다.
